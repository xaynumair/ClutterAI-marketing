# ClutterAI marketing site

The public site at [clutter-ai.com](https://clutter-ai.com). Next.js (App Router), no
UI framework, no analytics. The application itself lives in the sibling
`cutter-ai` repository and is served from app.clutter-ai.com.

## Run it

```bash
npm install
npm run dev
```

Then open http://localhost:3000. `npm run build` type-checks and builds;
`npm run lint` runs ESLint.

## Where things live

| Path | What |
|---|---|
| `app/globals.css` | Design tokens, typography, buttons, nav, footer, and the shared `.sc-*` scene styles |
| `app/lib/plans.ts` | **The only place with a price.** Copied from the app's `convex/planCatalogue.ts` and `src/lib/planCopy.ts` |
| `app/lib/apps.ts`, `app/lib/agents.ts` | The five Workspace apps and eight agents, with taglines from the app |
| `app/lib/integrations.tsx` | The thirteen live integrations, inline SVG marks |
| `app/lib/site.ts` | URLs, support address, tagline, trial length |
| `app/components/scenes/` | The animated product miniatures, a copy of the app's sign-in scenes |
| `app/components/home/` etc. | One client component + one prefixed stylesheet per page |
| `app/api/contact/route.ts` | Support form → Resend. Needs `RESEND_API_KEY` (optional `CONTACT_FROM`, `CONTACT_TO`) |
| `app/privacy`, `app/terms`, `app/refund` | Legal pages (server components, shared `components/legal/`) |

Pages are server components that export `metadata` and render a client body.
`app/opengraph-image.tsx`, `sitemap.ts` and `robots.ts` are generated by Next.

## Keeping it true

When plans, limits, agents or integrations change in the app, update the file
in `app/lib/` and nothing else. `WEBSITE_V2_PLAN.md` records the audit that led
to this version and the decisions behind it.

## Environment

| Variable | Purpose |
|---|---|
| `RESEND_API_KEY` | Sends the support form. Without it the form falls back to a mailto link. |
| `CONTACT_FROM` | Verified sender on the Resend account (default `ClutterAI Support <support@clutter-ai.com>`) |
| `CONTACT_TO` | Where support messages go (default `support@clutter-ai.com`) |
